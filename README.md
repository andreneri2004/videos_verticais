🎬 videos_verticais

Projeto desenvolvido em Flutter com o objetivo de praticar e aprender conceitos importantes do framework, criando um app no estilo TikTok, com rolagem de vídeos verticais.

Este repositório faz parte do meu processo de aprendizado em Flutter, aplicando boas práticas, widgets e pacotes essenciais para construção de interfaces modernas e interativas.

🚀 Funcionalidades

Exibição de vídeos no formato vertical

Navegação no estilo feed

Detecção de gestos do usuário

Aplicação de gradientes e sobreposições visuais

Controle de loops em vídeos

Uso de Stacks para empilhamento de elementos

Controle de assets e pacotes externos

Criação de mappers para melhor organização do código

Implementação de asserções para garantir consistência

Utilização de controladores de vídeo para manipulação da mídia

🛠️ Tecnologias e Conceitos Estudados

Flutter SDK

Manejo de assets (imagens, ícones e vídeos)

Paquetes (Packages) do ecossistema Flutter

Gesture Detector para interações com o usuário

Posicionamento de Widgets

Mappers para abstração e transformação de dados

Gradientes aplicados em layouts

Loops em animações e vídeos

Asserções para segurança no código

Stacks para camadas de widgets

Controladores de vídeo (video_player package)

📚 Objetivo do Projeto

Este projeto não tem fins comerciais, mas sim educacionais.
Foi desenvolvido como parte do meu aprendizado em Flutter, inspirado no funcionamento do TikTok para explorar diferentes recursos visuais e interativos.

▶️ Como executar o projeto

Clone este repositório:

git clone https://github.com/seu-usuario/videos_verticais.git


Acesse a pasta do projeto:

cd videos_verticais


Instale as dependências:

flutter pub get


Execute o app:

flutter run
